# Contributing

Thanks for helping improve PSXperia Remastered.

## Before opening an issue or pull request

- Search existing issues first.
- Describe the exact app milestone/build, Windows version, Xperia model, and Android version.
- Include reproducible steps and relevant non-copyrighted logs.
- For compatibility reports, identify the game title and region/serial, plus the test conditions and observed symptoms.

## Never upload

Do not upload or link to:
- PS1 disc images or extracted game files.
- Sony runtime APKs or ZPAKs.
- BIOS/firmware dumps.
- Converted APKs/data folders containing game content.
- Copyrighted cover art or other material you do not have permission to redistribute.

## Pull requests

- Keep changes focused.
- Explain the problem and the approach.
- Include tests or a manual test plan.
- Do not claim physical Xperia compatibility unless it has been tested on real hardware.
- Preserve third-party license and attribution notices.

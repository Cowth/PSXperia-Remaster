# Milestone 06.6 — PlayStation Pocket Workspace

## Purpose
Turn the shell into a violet PlayStation Pocket-inspired workspace while preserving the original PSXperia conversion engine and user-owned Sony runtime workflow.

## Changes
- Animated violet wave background: the supplied wave artwork is gently translated and opacity-pulsed by WPF animations. A reduced-motion option disables animation. The source artwork itself is static; motion is generated by the WPF presentation layer.
- Soft violet bubble glows and rounded purple cards reinforce the Xperia Play / PlayStation Pocket visual direction without embedding Sony system sounds or proprietary UI assets.
- Dark ComboBox template and dark item containers address the white-on-white game selector/dropdown issue.
- Game Library is now a separate converted-games shelf with large cover-art tiles, title/serial, conversion date, open-output-folder and remove-from-shelf actions.
- Existing PSXperia output can be added to the shelf using **Add existing APK**. The app verifies the expected matching data directory before recording it; it does not move or delete the APK or data.
- Successful conversions are recorded to `%LOCALAPPDATA%\PSXperiaRemastered\converted-games.json` only after the expected APK and game-specific data directory exist.
- Compatibility Lab saves per-game status, symptoms, and optimization notes to `compatibility.json`.
- Settings persist animated background, reduced motion, optional UI system sounds (off by default), and automatic artwork lookup to `settings.json`.
- Xperia Device page explains the next ADB workflow but explicitly reports that connection detection is not implemented in this milestone.
- Converter remains an in-app UserControl in the main workspace. Error diagnostics remain in a dialog; successful completion is shown inline.

## Data safety
- Removing a converted game removes only its shelf record. It never deletes the APK or game data.
- Importing an existing APK checks for `data/com.sony.playstation.<TITLE_ID>` alongside the APK before adding it.
- The original conversion JAR and conversion format are unchanged in this UI milestone.
- UI sound effects use optional Windows system tones only. No PlayStation audio is bundled.
